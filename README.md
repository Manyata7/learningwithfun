# 🌈 Learning Made Fun - Kid's School Portal (Classes 1 to 5)

> **Created by Shivram Gawale** ✨

An interactive, colorful, bilingual (English & Hindi) digital classroom web portal for primary school children (Classes 1 to 5). Built with pure HTML5, CSS3, JavaScript, Web Speech API (cute soft voice narration), Web Audio API, and Canvas Confetti.

---

## 🌟 Key Features

1. **Grade Curriculum (Classes 1 to 5)**:
   - **🔤 English**: Phonics alphabet (A-Z with audio), interactive sentence builder game with draggable word tiles.
   - **🔢 Maths Hub**:
     - *Class 1*: Visual counting 1-50 & number cards.
     - *Class 2*: Object addition & Frog Number Line jump (0-10).
     - *Class 3*: Subtraction balloon popping lab & 2D/3D shapes.
     - *Class 4*: Multiplication dot array matrix (rows × columns) & Indian Currency Note Counter.
     - *Class 5*: Pizza fraction slicer, live percent/decimal converter (`3/4 = 75% = 0.75`), and geometry angle explorer.
   - **🇮🇳 Hindi Varnamala**: All 13 Swar (स्वर) & 37 Vyanjan (व्यंजन & संयुक्त व्यंजन) with pictures, pronunciations & English meanings.
   - **🌍 EVS Video Explainers**: Interactive scene player for Body Parts, Animals, Plants, Food, Transport, Water Cycle & Landforms.
   - **📖 Be Kind Story Corner**: Illustrated moral stories with automatic video auto-play loop, scene transitions, and bilingual English/Hindi audio.

2. **Bilingual Accessibility (English 🇬🇧 & हिन्दी 🇮🇳)**:
   - Global top header switcher toggles titles, navigation, descriptions, lessons, and voice narration instantly.

3. **Cute Soft Voice Engine**:
   - Soft chime sound effects, high-pitched cute voice (`pitch = 1.35`), and relaxed storytelling pace (`rate = 0.72`).

## 🚀 Easy 1-Click Deployment Options

### Option 1: GitHub Pages (Free)
1. Push this repository to GitHub: `https://github.com/Manyata7/learningwithfun.git`
2. Go to repository **Settings** ➔ **Pages**.
3. Under **Build and deployment**, select **Source: Deploy from a branch**.
4. Choose `main` branch and `/ (root)` folder ➔ Click **Save**.
5. Your website will be live at: `https://manyata7.github.io/learningwithfun/`!

### Option 2: Vercel (Recommended - 1-Click Zero Config)
1. Go to [Vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New Project** ➔ Select `learningwithfun` repository.
3. Click **Deploy**! (Vercel automatically detects `vercel.json` and publishes your site instantly with SSL).

### Option 3: Netlify / Cloudflare Pages
- Drag and drop the workspace folder or connect your GitHub repository for instant static site hosting.
